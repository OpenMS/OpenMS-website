We're excited to announce the latest release of OpenMS, a substantial update and an important step toward our next major version!

OpenMS 3.6.0 addresses many of your feature requests, including:

- Extended ion mobility support (FAIMS and PASEF)
- Arrow and Parquet support for modern, high-performance data workflows
- New nanobind-based pyOpenMS bindings for more Pythonic and faster Python code
- A restructured build system with vcpkg support, replacing the contrib repository

And that's just the highlights, there's a lot more packed into this release!
Grab it [here](https://github.com/OpenMS/OpenMS/releases/tag/v3.6.0).

Windows users: you may see a security prompt when running the installer. Just click "More Info" and then "Run Anyway" to proceed, detailed instructions can be found [here](https://openms.readthedocs.io/en/latest/about/installation/installation-on-windows.html).
