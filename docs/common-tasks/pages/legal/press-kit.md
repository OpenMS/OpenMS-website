# Press kit

**Address:** **https://openms.de/press-kit/**  ·  **Linked from:** footer → LEGAL

Logos and templates for people who write about OpenMS.

## What you can change

| Part of the page | What you can change | Where it is | How |
|------------------|---------------------|-------------|-----|
| All the words | The words | `layouts/partials/press-kit-main.html` | Ask the web team ([who?](../../../workflow/who-to-ask.md)) |
| The files to download (logos, PowerPoint, Word) | Replace a file | `static/press-kit/` | [Add images](../../add-images.md) |

When you replace a download, keep **the same file name**, or ask the web team to change the link.

## How to make the change

- Words in **`layouts/`**: these are part of the design. Ask the web team ([who to ask](../../../workflow/who-to-ask.md)).

## Leave these to the web team

- How the page looks: `assets/css/overrides/press-kit.css`.
