Get involved

Ways to contribute

Your choices aren’t limited to programming — there are many areas where we need your help.

  1. Contribute to development

    You do not need to understand the entire codebase to start — many people begin with docs, bug reports, or small fixes. Pick the project you want to contribute to:

    • OpenMS-lib
    • pyOpenMS
    • pyOpenMS Viz
    • OpenMS WebApps

  2. Build from source

    Compile the latest OpenMS with platform-specific guides for Windows, macOS, and Linux.

    Windows macOS Linux

  3. Educational materials

    Tutorials, how-tos, notebooks, and videos for the User Guide.

    Explore OpenMS-Docs →

  4. Graphic design

    Illustrations for docs, images for the site, and visual polish across the project.

    Get in touch →

  5. Website development

    Fix bugs, improve layout, or add content on the website repo.

    Browse open issues →
